# Customer Support Workflow (n8n)

An AI-powered workflow that reads incoming support emails,
classifies them by urgency using Gemini, and sends
auto-replies for common questions.

## Tools used
n8n, Gmail API, Google Gemini, Google Sheets

## How it works
1. Gmail trigger detects new support email
2. AI agent classifies the issue type
3. Common questions get instant auto-reply
4. Complex issues are logged to a sheet and flagged
